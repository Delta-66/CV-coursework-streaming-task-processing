## 真实数据运行结果

两条真实 ALOHA 轨迹均完整逐帧读完，共 **819 个原生时刻**；两相机共解码 1638 帧图像。默认 1 Hz 采样产生 **33 次决策**。主判定使用顶视图和实测右夹爪，右腕图供人工核查。没有在线读取失败标签、目标 action 或目标 EEF。

| 片段 | 实际输入与判断 | 提醒及动作 |
|---|---|---|
| episode 0，0—6 s | 定位、接近、刀架附近抓取准备；遮挡时保持未知 | 无失败提醒，不因尚未成功判失败 |
| episode 0，7—8 s | 观测到闭合尝试，但没有可靠持刀效果 | 抓取确认/信息不足，不报告成功 |

| episode 0，10 s | 连续证据再次支持相同偏差 | 同一事件确认；高层恢复抓取条件，低层先安全打开右夹爪 |
| episode 0，11 s | 同一问题持续 | 更新原事件，无新提醒 |

最终标签文件在推理结束后独立核对：episode 0 标注 failure，18 标注 success。系统仍将两条**整任务成功**保持未知，因为主视觉后端没有验证切割效果与刀具归位。这是明确的支持边界，不用最终标签补齐在线判断。

失败片段在 9 s 疑似、10 s 确认，但**不能报告相对首次可检测时刻的检测延迟**：没有对应人工标签，avoid keyframe 不是首次可检测时刻。两个例子被用于开发阈值，不能据此报告无偏准确率、Precision/Recall/F1 或跨任务泛化。

本次主运行墙钟耗时约 **8.78 s**（包含视频读取、输出保存等）；决策函数平均约 **10.4 ms / 7.3 ms**（失败/正常样例），单次最大约 16 ms。该数值不包括视频解码和保存，不等同于真机控制系统端到端延迟保证。

## 实际高低层纠错示例

以下摘自 episode 0 的 10 s 输出；完整字段、时间戳证据和图片引用见 `correction_example.json`。

```json
{
  "timestamp": 10.0,
  "execution_status": "confirmed_failure",
  "event_id": "event-0001",
  "type": "grasp_not_established",
  "recovery_goal_id": "event-0001:restore_reliable_grasp",
  "high_level": {
    "blocked_subtask": "携刀进入工作区并执行切割",
    "failed_precondition": "reliable_grasp",
    "next_recovery_subgoal": "重新建立刀柄定位、两指对齐及可靠夹持条件",
    "resume_when": "连续新观测支持刀离开刀架且随夹爪运动，再恢复携刀转移"
  },
  "low_level": {
    "action_type": "open_gripper",
    "object": "knife",
    "actuator": "right_gripper",
    "coordinate_frame": "right_gripper_actuator_no_translation",
    "numeric_command": null,
    "directly_executable": false,
    "post_checks": [
      "右夹爪确实打开",
      "刀仍在刀架且未被拖动",
      "重新观测刀柄与两指的相对位置，再决定下一动作"
    ]
  },
  "actually_executed": false,
  "execution_receipt": null
}
```

具体动作要求先确认刀与夹爪分离，且夹爪没有其他物体、可安全保持当前位姿；后者需要执行器检查。只生成“打开”这个下一动作，**没有同时生成移动、再闭合、抬升、切割的长串计划**。诊断的原因假设仍未确认，不断言夹持力/摩擦不足。

## 实际发现与修复

1. Qwen 首轮空间/运动矛盾与第二轮缺字段：严格拒绝，原始输出留档；没有填充假事实挽救结果。主路线收敛为可核查经典视觉，并缩小真实支持范围。
2. 模态冲突的一帧曾被后续连续证据统计重新使用：新增 `effect_usable` 门控；相邻新证据不足时不能提前宣称恢复。对应回归测试通过。
3. 正常持刀随后离开工作区时，初版会回到抓取确认阶段：改为当前阶段未知，保留已经确认的历史子目标；不凭观测缺口编造重新抓取。对应测试通过。
4. 旧测试首次使用系统临时目录失败：只给本次测试进程指定工作区内临时目录，113 项重跑通过；没有改系统权限、用户环境或原代码。
