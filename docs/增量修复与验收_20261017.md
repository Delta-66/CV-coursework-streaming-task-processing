## 4. 修复内容及对应证据

### 4.1 离线报告标签与统计

旧 `build_review.py` 对字符串 `episode_success` 直接做布尔判断，导致 `"failure"` 也被当成真。这是报告错误，不代表检测器真的误报。

新的离线统计显式解析 `success` / `failure`，其他值报错；分别统计失败确认、疑似通知与恢复通知，不把全部 `notify` 混算为失败误报。完整读取也不再是常量：逐条核对元数据期待长度、Parquet 消费行数、顶视/腕视频消费帧数，并单列决策时钟覆盖。

原错误报告和原始决策日志保留。基于上轮原始日志重算的正确报告为 `repair_acceptance_20261017/review_summary_v2_final.json`，其 `run` 仍明确指向旧 `multimodal_20261017/final_run`。它正确保留旧19尚未完成的语义缺口，**不是本轮新 accepted_run 的结果**。合法标签、非法标签以及成功/失败与提醒/确认的组合均有回归检查。

### 4.2 A：明确分离反证优先于短期持有假设

`tracking.py` 先处理当前 `contact=separate` 或 `released=yes`，及时将当前夹持置否并移除过期连接锚点。即使粗代理 `tool_on_board`、`robot_at_board` 同时为真，也不能覆盖明确释放；冲突写入 `evidence_conflicts`。正常回架释放结束旧连接，不再作为随后失抓的前件。

验证采用“可靠持刀→当前回架分离释放，但粗代理仍为真”的合成组合反例；不是自然滑落视觉样例。

### 4.3 B：曾持刀不替代当前夹持前置条件

`attempt_held` 保留“本次尝试曾成功”的历史意义。尚未切割时提前回架释放，若随后当前明确空手、关节确有运动且再次进入砧板/后续操作区域，则建立 `prerequisite_unmet` 并进入受阻阶段。正常回架、驻留、视觉未知本身不足以触发失败。

验证采用“打开→闭合→可靠持刀→提前回架→空手继续工作”的合成语义序列；真实六条不提供对应自然重试链。

### 4.4 C：砧板/其他支撑面的实际重抓能结束旧事件等待

实际观察到新的开闭尝试时，建立一个有界 `attempt_context`，记录对象、支撑位置、开始时间、引用、预期效果与坐标系。砧板/其他支撑面重抓后，只有连续清晰证据同时支持“刀留在原支撑面、闭合两指与刀明确分离、同图定位显著分离”时才确认新的抓取失败。

仅等待时间长、仅夹爪闭合或尚未抬起都不能触发该结论。旧事件可以因实际重试转为 `closed_for_retry`，新成功、新失败与信息不足分别更新恢复状态；实际重新打开时允许回到定位准备。输出重试建议不会增加 `attempt`，也不会伪造动作已发生。

### 4.5 D：恢复条件不再机械套用当前位置

`recovery.py` 使用已记录的原支撑面或“刀与两指保持连接并连续随动”描述恢复条件。当前刀在 `gripper` 时，不再生成“刀离开夹爪内”这种相反目标。高层恢复目标、低层当前动作、执行器检查与执行后状态继续共享事件编号和恢复目标编号。

A—D 修改前反例与修改后结果分别保存在 `state_before.txt`、`state_after*.txt`、`state_repair_examples.json` 等记录中。其证据类别明确为合成语义逻辑，不用于声称真实视觉恢复准确率。

### 4.6 已到达 25 FPS 关节区间，避免端点采样混叠

`source.py` 在顺序消费原生关节样本时，使用 `dynamics.JointInterval` 汇总区间路径长度和最大实测速度。决策仍约 1 Hz；没有把整条轨迹载入推理缓存。

完整、连续且有效的原生区间才能支持“本区间未检测到运动”。如果只有两个端点 qpos 接近、当前 qvel 较低，则输出 `low_motion_support`，不能据此断言两次判断之间没有往复运动。缺失、无效、覆盖不全、未来或不合时钟的区间不能伪装为完整证据。原始阈值为显式工程配置，未经物理单位标定，不解释成准确速度或成功概率。

区间往复反例属于构造的设计回归。19 的旧漏确认已由真实像素定位到视觉候选连通问题，不能把关节混叠风险反写成已证明的19根因。

### 4.7 19 的真实操作链及2/8阶段

19 的6—8秒腕图中，亮刀刃与浅色香肠亮边在原颜色掩膜下连成过宽轮廓，导致细长刀刃候选被拒绝；部分反光还延伸到两指下方。只裁掉下部仍失败，该中间结果保留在 `visual_regression_after.txt`。最终方案保留两指尖端上方实际可见的长刃段，用纵向开运算去掉短横亮桥，同时保留颜色、中央细长几何、两指连接和离架证据要求。

修复没有写入 episode 编号、未来时刻或最终标签，没有删除“参考→有效操作→新增分离效果→归位释放”的完成链。原始三条小实验与最终 `accepted_run` 均保持1 Hz。19在8秒确认刀—香肠操作、11秒连续确认新增分离效果、16秒确认完整完成；18在20秒确认完整完成。最终结果未用离线标签补齐。

2/8 的旧接近判断过度依赖“机械手遮挡刀架”，而实际机器人经常位于架上方或侧方，刀仍清晰可见。新增当前顶视相对初始参考的近架机器人粗投影证据，只服务接近/准备阶段，不冒充指尖、接触或三维距离。2的联合定位进一步支持对齐准备；8定位混连时保持未知，但实际开闭与区域关系仍支持进入抓取效果确认。

阶段核查记录要求具体时刻和实际证据，不能用某个阶段名曾经出现来证明整个时序正确。`visual_real_evidence.json` 和最终 `manual_review.json` 保留期望阶段、程序输出及差异。

## 5. 真实方向交接与建议边界

新增 `localization.py` 从当前腕图检测“细刃变为宽白柄”的可见颈部横截面，并检测左右两指实际内缘角点。`knife_handle_xy` 是可见柄颈的抓取参考点，`gripper_xy` 是两指内缘的中点；二者均不使用整刀或机器人区域质心代替。遮挡、刀架与手指混连、柄颈截断或宽度变化不清时返回 `None`。

2的2秒和3秒真实图像中，两点可核查。方向采用共享 `image_alignment_directions`，坐标系为 `cam_right_wrist_image_x_right_y_down`，位置以图像归一化0—1000表达，死区为50。2秒给出图像左侧方向，3秒给出图像下方方向；后者水平差未超过死区，因此不添加左侧方向。

这些记录是**基于当前真实像素的独立条件化方向交接**：当前夹爪打开，刀柄/两指可见；执行器仍须独立验证深度、姿态、路径与坐标映射，才能转换为物理移动。停止条件是新图像进入二维对齐死区或目标丢失，之后还要检查独立接触准备。没有位移、角度、速度或夹持力数值，没有三维控制指令。

六条真实失败确认之后没有再次打开夹爪，因此自然事件链中仍未发生“失败后重新打开→图像对齐→准备→闭合→效果恢复”的全过程。不能为展示 `align_in_image` 构造未发生的事件或把早期帧接到后来的失败上。真实保持与开爪建议有效，真实定位验证方向交接；完整恢复推进、独立准备后的闭合与再试分支属于合成验证。

所有回放输出持续保持：

```json
{
  "mode": "advisory_replay",
  "actually_executed": false,
  "execution_receipt": null,
  "outcome_attributed_to_suggestion": false
}
```

原视频后续的成功、归位或状态变化不能归因于建议已执行。

## 6. 因果性、容量与故障处理

系统按原生时间递增消费完整轨迹，决策每25帧一次。非决策帧也顺序读取，但不能使用未来样本进行对齐、平滑、选帧或归一化。当前模态超时、无效或缺失均显式标记；每条轨迹重置源、视觉参考、观测、阶段、事件和恢复状态。流结束不等于任务完成。

| 用于推理的状态 | 容量边界 |
|---|---|
| 历史观测 | 最多4条、4秒窗口；每条最多当前两路图像 |
| 语义特征 | 最多6条；每条 `measurements` JSON最多9000字符；总体特征负载另有限制 |
| 事件与证据 | 最多4个事件，每事件最多4条证据；持续问题更新原编号 |
| 结构锚点与对象 | 最多8个锚点、3个对象；一次当前尝试上下文，最多6字段 |
| 视觉参考与跟踪 | 初始参考图1张、掩膜最多4个、粗视觉轨迹最多2条、腕部几何记录最多3条、食物参考最多5项 |
| 每次视觉输入 | 当前顶视＋起始顶视参考＋按需当前腕图，合计最多3张 |
| 原生关节区间聚合器 | 6个前位置值＋6个路径和，即12个数值；最多10个固定标量；不缓存原生样本序列 |
| 区间快照 | 每条观测至多一个14字段摘要，随4条观测窗口淘汰；不是额外无限历史 |
| 新联合定位 | 当前轮廓至多16点、5条柄颈横截面及固定字段，进入原9000字符测量/6条特征范围；没有新增跨帧定位缓存 |
| 恢复上下文 | 最多一个事件副本；等待类型和计数固定，计数饱和到3 |
| 模型对话、持久KV、累计日志读取 | CPU主方案均为0；审计日志只写出，不回读作推理记忆 |

因果验收包含真实公共前缀、人工修改后缀，覆盖读取、原生区间聚合、解码、对齐、视觉候选、联合定位、有限记忆、状态、事件与建议。长流采用真实像素循环构造的动态压力输入验证容量，并明确它不是自然连续长轨迹。缺图、黑图、视频打开/解码错误、过期和初始等待采用故障注入；不把注入测试称为真实遮挡标注实验。
